# RAMAN AGRO INDUSTRIES

Static website for Raman Agro Industries, a cotton ginning, pressing, warehousing, and agri-commodity business based in Jintur, Maharashtra.

## Project Structure

- `index.html` — main website page
- `assets/css/styles.css` — website styling
- `assets/js/main.js` — JavaScript for mobile menu, animations, and footer year
- `images/` — all website images and branding assets
- `.github/workflows/deploy.yml` — GitHub Pages deployment workflow

## Local Preview

Open `index.html` in a browser to view the site locally.

## GitHub Deployment

This project is configured for GitHub Pages and can be published through the repository's Pages settings.
