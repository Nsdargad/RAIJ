# Raman Agro Industries

Static website for Raman Agro Industries, a cotton ginning, pressing, warehousing, and agri-commodity business based in Jintur, Maharashtra.

## Project files

- `index.html` — main website page
- `assets/css/styles.css` — website styling
- `assets/js/main.js` — mobile navigation, animations, and footer year
- `images/` — website photographs, process graphics, and branding

## Local preview

Open `index.html` in a browser.

## GitHub Pages

GitHub Pages is configured to build and deploy the repository root. Push changes to `main`; the Pages workflow in the repository's **Actions** tab builds and publishes the site.
